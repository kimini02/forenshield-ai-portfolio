# 사건 상세 딥페이크 분석 화면 재구성 계획

## 목표

사건 상세 페이지의 우측 영역을 레퍼런스 이미지처럼 `딥페이크 분석 중심 화면`으로 재구성한다.

핵심은 기존 `분석 요약` 카드 스타일을 유지하는 것이 아니라, 아래 구조를 그대로 맞추는 것이다.

```text
좌측 증거 파일 목록
└─ 우측 딥페이크 분석 영역
   ├─ 딥페이크 탐지 요약
   ├─ 탭 바
   ├─ 영상 플레이어 + 프레임별 위험도/모델 분석 정보
   └─ 주요 의심 구간 + 딥페이크 세부 항목별 점수
```

## 반드시 맞출 레퍼런스 구조

### 1. 우측 최상단: 딥페이크 탐지 요약

우측 영역의 가장 위에는 선택 증거 기본정보 카드가 아니라 `딥페이크 탐지 요약` 카드가 온다.

구성:

```text
딥페이크 탐지 요약
├─ 자동 탐지 결과
├─ 모델 탐지 점수
├─ 판정 임계값
├─ 분석 신뢰도
├─ 품질 점수
└─ 분석값 검토
```

스타일:

- 카드 전체는 `rounded-xl border border-border bg-card shadow-sm`
- 내부 지표는 6개 동일 너비 카드
- 카드 높이는 낮고 조밀하게
- 큰 숫자는 필요한 곳만 강조
- 라벨은 작고 연하게
- 전체적으로 `font-black` 사용 금지

표시 예시:

| 항목 | 예시 |
| --- | --- |
| 자동 탐지 결과 | `조작 의심 낮음` |
| 모델 탐지 점수 | `0.08` |
| 판정 임계값 | `0.72` |
| 분석 신뢰도 | `94%` |
| 품질 점수 | `95 / 100` |
| 분석값 검토 | `대기` |

하단 안내 문구:

```text
자동 분석 결과이며, 단독으로 콘텐츠의 진위나 법적 사실을 확정하지 않습니다.
```

### 2. 탭 바

딥페이크 탐지 요약 카드 바로 아래에 탭 바를 둔다.

탭 순서:

```text
분석 요약 | 탐지 상세 | 딥페이크 · 모델 분석 | 무결성 검증 | 메타데이터/보고서
```

현재 선택된 탭은 `딥페이크 · 모델 분석`이다.

스타일:

- 레퍼런스처럼 카드 안의 상단 탭처럼 보이게 한다.
- active 탭은 파란색 underline.
- 탭 높이와 텍스트 크기는 고정.
- 클릭 시 레이아웃이 흔들리지 않게 한다.

### 3. 본문 상단: 2컬럼

탭 아래 본문은 2컬럼으로 구성한다.

```text
좌측: 영상 플레이어
우측: 프레임별 위험도 + 모델 분석 정보
```

권장 비율:

```text
grid-cols-[minmax(0,0.95fr)_minmax(0,1.45fr)]
```

### 4. 좌측: 영상 플레이어

구성:

```text
영상 플레이어
├─ 보기 모드: 원본 / 오버레이 / 히트맵
├─ 영상 프리뷰 영역
└─ 컨트롤 바
```

영상 프리뷰:

- 16:9 비율
- 실제 썸네일/영상 URL이 있으면 사용
- 없으면 neutral placeholder
- 레퍼런스처럼 너무 튀는 컬러를 쓰지 않는다.

컨트롤 바:

- 재생 버튼
- 현재 시간 / 총 시간
- progress slider
- 볼륨
- 배속
- 전체화면

이번 단계에서는 실제 동영상 플레이어 기능을 깊게 구현하지 않는다.
화면 구조와 시각적 위치를 먼저 맞춘다.

### 5. 우측: 프레임별 위험도

구성:

```text
프레임별 위험도 (모델 점수)
├─ 범례: 낮음 / 보통 / 높음 / 분석 불가
├─ y축: 1.00 / 0.72 / 0.50 / 0.25 / 0.00
├─ 임계값 dashed line
└─ 시간축: 00:00 ~ 00:30
```

데이터 정책:

- 백엔드가 frame score 배열을 주면 그대로 사용한다.
- 없으면 실제 차트 대신 상태 UI를 보여준다.
- `riskScore` 하나로 막대 차트를 가짜 생성하지 않는다.

상태 UI 문구:

```text
프레임별 분석 결과가 없습니다.
```

### 6. 우측 하단: 모델 분석 정보

프레임별 위험도 아래에 2열 정보 표를 둔다.

왼쪽:

- 분석 모델
- 모델 버전
- 분석 작업 ID
- 분석 프레임 수
- 유효 프레임 수

오른쪽:

- 얼굴 검출 프레임 수
- 프레임 추출 간격
- 입력 해상도
- 판정 임계값
- 처리 시간

스타일:

- 행 단위 border
- label은 `text-muted-foreground`
- value는 `font-medium` 또는 `font-semibold`
- 굵고 큰 폰트 금지

### 7. 하단 왼쪽: 주요 의심 구간

구성:

```text
주요 의심 구간
└─ 의심 구간 카드 또는 empty 상태
```

데이터가 없을 때 문구:

```text
판정 임계값을 초과한 연속 의심 구간이 발견되지 않았습니다.
```

주의:

- 이 문구는 “안전하다”는 판정이 아니다.
- “정상”, “조작 아님”처럼 단정하지 않는다.

### 8. 하단 오른쪽: 딥페이크 세부 항목별 점수

구성:

```text
딥페이크 세부 항목별 점수
├─ 얼굴 경계 불연속
├─ 시간축 일관성 저하
├─ 질감 · 주파수 이상
├─ 조명 · 색상 불일치
└─ 오디오 · 립싱크 불일치
```

각 항목:

- 점수
- 라벨: 낮음 / 보통 / 높음 / 해당 없음

데이터가 없을 때:

- 항목별 `-`
- 또는 전체 empty 상태

## 데이터 정책

real 모드에서 가짜 분석 결과를 만들지 않는다.

금지:

- `riskScore`만으로 frame score 생성
- `riskScore`만으로 suspicious segment 생성
- `riskScore`만으로 detection finding 생성
- API 실패 시 mock fallback
- raw AI summary를 위험 등급/세부 점수로 표시

허용:

- 백엔드가 내려준 명시 필드 표시
- `moduleResults`가 있으면 모델 점수 카드에 사용
- `confidenceScore`는 `0~1`이면 `0~100`으로 표시 정규화
- 필드가 없으면 `-` 또는 상태 UI 표시

## 폰트/스타일 기준

- 카드 제목: `text-base font-semibold`
- 섹션 제목: `text-sm font-semibold`
- 라벨: `text-xs font-medium text-muted-foreground`
- 값: `text-sm font-medium` 또는 `text-lg font-semibold`
- 큰 숫자: 최대 `text-2xl`
- `font-black` 사용 금지
- `bg-card`, `border-border`, `text-foreground`, `text-muted-foreground` 우선 사용
- 색상은 teal/blue/orange/red 상태 컬러만 제한적으로 사용
- 밝은 색을 쓰면 `dark:` 변형을 함께 넣는다.


## 건드릴 수 있는 범위

이번 작업은 `딥페이크 분석 화면`을 그대로 맞추는 것이므로 다음은 수정 가능하다.

- 딥페이크 탐지 요약 위치와 구조
- 탭 바 안에서 `딥페이크 · 모델 분석` active 구조
- 딥페이크 탭 내부 레이아웃
- 영상 플레이어 placeholder
- 프레임 위험도 상태 UI
- 모델 분석 정보 표
- 주요 의심 구간
- 세부 항목별 점수

## 주의할 범위

다른 작업자가 동시에 고치는 영역과 충돌하지 않도록, 아래는 꼭 필요할 때만 최소 수정한다.

```text
app/cases/[id]/_components/evidence-summary-card.tsx
app/cases/[id]/_components/summary-meta-item.tsx
app/cases/[id]/_components/summary-tab.tsx
```

## 완료 기준

- 우측 영역 최상단에 `딥페이크 탐지 요약` 6개 지표 카드가 있다.
- 탭 바에서 `딥페이크 · 모델 분석`이 active다.
- 본문은 레퍼런스처럼 좌측 영상 플레이어, 우측 차트/모델 정보로 배치된다.
- 하단에 주요 의심 구간과 세부 항목별 점수 카드가 있다.
- 폰트가 작고 과하게 굵지 않다.
- real 모드에서 가짜 분석 결과를 만들지 않는다.
- 실제 데이터가 없을 때는 상태 UI로 표시한다.
- `pnpm build`가 통과한다.
